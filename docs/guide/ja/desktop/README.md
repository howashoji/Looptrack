# デスクトップ版

[ガイドの目次](../README.md)

デスクトップ版の利用者向けの入口です。アプリの取得から AI エージェントとの接続まで、それにその後の使い方・更新・アンインストールを扱います。

デスクトップ版は 1 台の PC を 1 人で使うための形です。ターミナルは開かなくてかまいません。
アイコンをダブルクリックすれば、手元のサーバが起動して既定のブラウザに画面が開きます。サーバが待ち受けるのは 127.0.0.1 だけで、データは SQLite のファイル 1 つに収まります。
初めて起動するとブラウザに初回設定の画面が出ます。ここで決めるのは管理者・二段階認証・最初のプロジェクトです。
タスクトレイのアイコンからは画面を開く・設定を開く・AI の MCP の接続設定をコピーする・CLI を使えるようにする・ログイン時に起動する・終了する、といった操作ができます。macOS ではメニューバーにアイコンが出ます。
Windows 向けにはインストーラもあります。スタートメニューに登録され、「アプリ」の一覧からアンインストールできます。

管理者権限はどの OS でも要りません。
複数人で共有するサーバなら[サーバ版](../server/README.md)を使ってください。
