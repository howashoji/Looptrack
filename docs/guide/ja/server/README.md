# サーバ版

[ガイドの目次](../README.md)

サーバ版の利用者向けの入口です。扱う範囲はサーバの立ち上げから AI エージェントとの接続まで、それにその後の管理と更新です。
サーバ・CLI・hook はどれも 1 つの実行ファイル `looptrack` で動きます。チームで共有するサーバにも端末から使う自分だけのサーバにもなります。
1 台の PC を 1 人でターミナルなしで使うなら？ [デスクトップ版](../desktop/README.md)のほうが手間がかかりません。
