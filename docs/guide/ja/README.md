## 用語

| 用語 | 意味 |
| -- | -- |
| サーバ | イシューを保存する `looptrack serve` です。ブラウザの画面・REST API・MCP を持ちます |
| CLI | 手元で動く `looptrack` です。`looptrack issue …` でイシューを操作します。サーバと CLI は同じ実行ファイルです |
| プロジェクト | イシューの入れ物です。slug（例 `demo`）と ID の接頭辞（例 `DEMO` → `DEMO-0001`）を持ちます |
| MCP | AI がツールとしてサーバを呼ぶための接続です。AI は CLI か MCP のどちらかでイシューを操作します |
| hook | AI のセッションの開始・ツールの実行後・停止といった決まった時点で動く小さな処理です |
| kit | 各プロジェクトに入れる hook・規則文・skill の一式です。必ず入る core と、選んで入れる loop があります |
