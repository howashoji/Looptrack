# Server edition

[Guide contents](../README.md)

This is where the server edition guide starts. It covers setting up the server and connecting your AI agent, then administering and updating the server.
The server, the CLI and the hooks all run from one executable, `looptrack`. It can be a server your team shares, or one you run for yourself from a terminal.
On your own, on one PC, with no terminal? The [desktop app](../desktop/README.md) gets you there with less work.

## Pages for the server edition

| Page | What it covers |
| -- | -- |
| [Getting started](getting-started.md) | From downloading `looptrack` to setting up the server, creating a project and connecting your agent |
| [Administration](admin.md) | Users, permissions, two-factor auth, project rules, token reports |
| [Updating](updating.md) | Updating the server and the CLI: what is automatic and what is manual, `self-update`, `install.sh --upgrade`, the looptrack you distribute to users |
